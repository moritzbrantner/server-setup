About This Example

What This Repo Is For

This repository exists so you can validate static site deployment without any runtime dependencies.

  1. The seeding script turns this folder into a standalone git repo under /srv/apps/simple-site.
  2. deploy_repo.py validates its server.conf and writes the generated registry entry.
  3. deploy_repo.py publishes it through Nginx and configures webhook redeploys.
