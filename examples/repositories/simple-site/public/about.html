About This Example

What This Repo Is For

This repository exists so you can validate static site discovery and deployment without any runtime dependencies.

  1. The seeding script turns this folder into a standalone git repo under /srv/apps/simple-site.
  2. discover-sites.sh normalizes its server.conf.
  3. sync-github-sites.sh clones it into a release directory and publishes it through Nginx.
